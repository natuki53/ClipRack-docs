ClipRackサポート

初期設定、権限、よくある問題について案内します。

基本の使い方
  1. 別のアプリでテキスト、画像、ファイル、URL、PDFをコピーします。
  2. ⌘⇧Vでクリップボード履歴を開きます。
  3. 矢印キーまたはマウスで選び、Enterまたはクリックで決定します。

よくある質問

DockにClipRackが見つかりません

ClipRackはメニューバーアプリのため、Dockには表示されません。メニューバーのアイコンまたは⌘⇧Vを使用してください。アイコンを非表示にした場合は、履歴パネルから設定を開いて再表示できます。

自動貼り付けが動作しません

「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」でClipRackを許可してください。許可しない場合も選択内容はクリップボードへ復元されるため、手動で⌘Vを押せます。

スクリーンショットが追加されません

「設定」→「詳細」でスクリーンショット取り込みを有効にし、macOSが実際に保存しているフォルダを選択してください。ClipRackは選択されたフォルダだけを監視します。

機密情報の取り扱い

パスワードマネージャーなどが機密・一時・自動生成として指定した項目は履歴へ保存しません。ただし、機密指定を提供しないアプリから秘密情報をコピーする際はご注意ください。

問い合わせ・不具合報告

GitHub IssueにmacOSのバージョン、ClipRackのバージョン、再現手順、期待した結果と実際の結果を記載してください。Issueは公開されるため、クリップボード内容、パスワード、個人情報、非公開ファイルを添付しないでください。
